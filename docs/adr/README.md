# Architecture decision records

ADRs preserve durable decisions that have meaningful alternatives or long-term consequences. Small bug fixes and local implementation changes do not require an ADR.

## Status values

- `Proposed`: under review and not authoritative.
- `Accepted`: current decision history.
- `Superseded`: replaced by a newer ADR.
- `Deprecated`: no longer applicable without a replacement.

Accepted decisions are append-only. A changed decision receives a new ADR, and both records link to each other.
